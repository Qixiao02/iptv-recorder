# IPTV Recorder UI 设计提示词文档

> 版本: 1.0 | 用途: 指导 AI 生成高质量 UI 设计

---

## 一、项目定位

### 1.1 产品简介
IPTV Recorder 是一款专业的 IPTV 节目录制管理系统，目标用户为追求高品质电视节目录制的进阶用户。

### 1.2 设计风格定位
```
风格关键词:
- 专业工具感 (Professional)
- 现代简洁 (Modern & Clean)
- 深色主导 (Dark-first)
- 科技质感 (Tech-forward)
- 高信息密度 (Information-dense)
```

### 1.3 设计原则
1. **功能优先** - 所有设计服务于功能实现
2. **效率至上** - 减少操作步骤，提升工作效率
3. **状态可见** - 实时反馈系统运行状态
4. **专业可信** - 视觉上传达稳定、可靠的印象

## 三、布局设计

### 3.1 页面框架

```
┌─────────────────────────────────────────────────────────────┐
│  [Logo]  仪表盘  频道  任务  录制  M3U源  直播      🔔  ⚙️  👤 │  ← 顶部导航 64px
├───────┬─────────────────────────────────────────────────────┤
│       │                                                     │
│  侧   │                                                     │
│  边   │                    主内容区                          │
│  导   │                                                     │
│  航   │                 (min-height: calc(100vh - 64px))     │
│       │                                                     │
│ 80px  │                                                     │
│       │                                                     │
└───────┴─────────────────────────────────────────────────────┘

布局模式:
- 默认: 侧边栏展开 (200px) + 内容区
- 紧凑: 侧边栏折叠 (80px) + 内容区
- 全屏播放: 隐藏侧边栏
```

### 3.2 内容区布局

```
标准页面结构:

┌─────────────────────────────────────────────────────────┐
│  页面标题                                    [操作按钮]   │  ← 页面头部
├─────────────────────────────────────────────────────────┤
│  [筛选条件] [搜索] [视图切换]              [批量操作]    │  ← 工具栏
├─────────────────────────────────────────────────────────┤
│                                                         │
│                     内容区域                             │  ← 主体内容
│                   (表格/卡片/列表)                       │
│                                                         │
├─────────────────────────────────────────────────────────┤
│                              共 100 条  < 1 2 3 ... >   │  ← 分页器
└─────────────────────────────────────────────────────────┘
```

### 3.3 响应式断点

```
断点定义:
  - Mobile: < 768px (单列布局)
  - Tablet: 768px - 1024px (双列布局，侧边栏可折叠)
  - Desktop: 1024px - 1440px (标准布局)
  - Wide: > 1440px (宽屏布局，最大内容宽度 1440px)
```

## 五、页面设计指南

### 5.1 仪表盘 (Dashboard)

**设计提示词:**
```
设计一个专业的 IPTV 录制系统仪表盘：

布局结构:
- 顶部: 4 个统计卡片横排 (总频道、今日录制、运行任务、存储使用)
- 中部: 左右分栏 (60/40)
  - 左: 运行中任务列表 (带实时进度条)
  - 右: 即将执行的任务时间线
- 底部: 最近录制文件表格 (最近 10 条)

视觉要求:
- 统计卡片: 带渐变背景，大数字突出显示
- 运行任务: 红色录制状态指示，实时进度动画
- 时间线: 垂直布局，节点圆点 + 连接线
- 整体深色主题，科技感
- 数据实时更新，有微动效

重点突出:
- 录制中任务最醒目 (红色强调)
- 关键数据一目了然
- 操作入口明显
```

## 六、动效规范

### 6.1 过渡时间

```
即时: 0ms (状态切换)
快速: 150ms (按钮悬浮、图标变化)
标准: 250ms (弹窗出现、面板展开)
缓慢: 400ms (页面切换、大型动画)
```

### 6.2 缓动函数

```
默认: cubic-bezier(0.4, 0, 0.2, 1)
进入: cubic-bezier(0, 0, 0.2, 1)
离开: cubic-bezier(0.4, 0, 1, 1)
弹跳: cubic-bezier(0.34, 1.56, 0.64, 1)
```

### 6.3 常用动画

```
淡入淡出: opacity 0 → 1
上滑进入: translateY(20px) → 0
缩放进入: scale(0.95) → 1
脉冲 (录制中): scale 1 → 1.05 → 1 (循环)
旋转: rotate 0 → 360deg (加载)
条纹流动: background-position (进度条)
```

### 8.1 图片处理
